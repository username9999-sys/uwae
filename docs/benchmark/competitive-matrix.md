## Comparison Framework

Each capability is evaluated based on:
- **Botasaurus**: Verified implementation status from source audit (unchanged unless a benchmark contradicts it)
- **Universal Web Acquisition Engine**: measured implementation status, using the four-value vocabulary below
- **Evidence**: the artefact a reader can open to check the claim
- **Gap Analysis**: what the evidence actually shows, including where Botasaurus is better or equal
- **Priority**: Relative importance for competitive positioning (High/Medium/Low) - retained from the Phase-0 audit
- **Confidence**: Level of certainty in the Phase-0 assessment (High/Medium/Low) - retained from the Phase-0 audit

### UWAE status vocabulary

| Status | Meaning |
|---|---|
| `Measured (cross-impl)` | Implemented **and** compared against Botasaurus on the same device under identical conditions; the evidence file is cited |
| `Measured (vs ground truth)` | Implemented **and** measured against fixture ground truth (protocol semantics, expected bytes, expected outcomes); **not** compared against Botasaurus |
| `Implemented` | Present in the source and covered by tests, but no benchmark artefact measures it |
| `Not yet verified` | No implementation in the source, or no evidence of any kind; the gap text states which of the two applies |

Rows are never deleted. A capability with no UWAE implementation says so in place, because an absent row is indistinguishable from "not applicable".
